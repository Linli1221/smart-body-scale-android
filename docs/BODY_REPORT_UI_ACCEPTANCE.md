# 身体报告单页 UI 验收清单

## 1. 视口与层级

- [ ] 375×812 基准下，抽屉收起高度约 97pt（12%）、半展开 503pt（62%）、全展开 747pt（92%）。
- [ ] 抽屉顶部距视口顶：715 / 308 / 65 pt。
- [ ] Z 轴顺序：背景微光 → 主舞台 → 遮罩 → 抽屉；全展开遮罩最大 45%。
- [ ] 主舞台缩放：1.00 / 0.72 / 0.50；半展开布局收缩 + 图层上移，视觉约 80pt。
- [ ] 顶部状态胶囊距安全区 12pt、高 28pt、圆角 14pt、6pt 呼吸点。
- [ ] 表盘直径 240pt、外环 4pt、中心 64pt 数字、18pt kg、等宽数字。

## 2. 抽屉手势

- [ ] 头部拖拽跟手，内容区滚动不误触抽屉。
- [ ] 释放速度 > 400pt/s 时按方向切换锚点；否则吸附最近锚点。
- [ ] 弹簧参数 dampingRatio 0.82、stiffness 280，切换无突跳。
- [ ] 收起态点击头部可展开；全展开向下拖可回到半展开。
- [ ] 全展开时内容可垂直滚动，时间轴可水平滚动，二者不冲突；内容底部避开手势导航栏。

## 3. 测量时序

- [ ] T+0：读数锁定，数字闪烁两次（每次 150ms），触发轻触觉。
- [ ] T+300：文案变「正在生成体成分报告」，流光扫描 1000ms。
- [ ] T+1300：抽屉自动半展开，主舞台上移/缩放。
- [ ] T+1500：8 张卡片按行序 50ms 间隔上移 12pt 渐显；数字 400ms 滚动。
- [ ] 同一记录阻抗补写不会重播整套动画。
- [ ] 旋转/重组不会重复触发已展示过的记录动画。

## 4. Bento 网格

- [ ] 抽屉满宽、容器左右 16pt，卡片间距 10pt，单卡宽 166.5pt。
- [ ] 体重+BMI 76pt；体脂+肌肉 96pt；水分+内脏脂肪 84pt；蛋白质+骨量 68pt；圆角 16pt。
- [ ] 体重卡：实测值 + 差值胶囊（下降绿/上升黄）；首次显示「首次基准记录」。
- [ ] BMI 卡：数值 + 偏瘦/标准/偏胖/肥胖胶囊。
- [ ] 体脂/肌肉：24pt 数值 + 4pt 三色区间条 + 圆形游标。
- [ ] 水分/内脏脂肪：22pt 数值 + 状态标签 + 28×28pt 语义微图标。
- [ ] 蛋白质/骨量：20pt 数值 + 8×8pt 状态点 + 双字标签。
- [ ] 点击卡片：1.5pt 主题色描边，图表切换指标；半展开时自动展开。
- [ ] 无 BIA：体重/BMI 正常，其余 6 卡显示 `--`，36pt 提示条横跨第一行上方。
- [ ] 数值为 `--` 时不显示游标/误导性状态。

## 5. 历史联动

- [ ] 时间轴点击历史节点，8 卡数值、差值、区间游标同步刷新。
- [ ] 单次/周均/月均切换后时间轴与图表刷新，选中项回到最新。
- [ ] 多成员筛选只影响历史/图表，不改变当前测量绑定。
- [ ] 全展开图表 180pt，默认体重；点击体脂等卡片纵轴/曲线切换。
- [ ] 单点历史显示发光锚点与「再测一次即可连成趋势曲线」。
- [ ] 无历史时显示空态，不绘制假曲线。
- [ ] 离线无设备但有历史时，初始半展开，状态胶囊「未连接设备 · 点击唤醒测量」。

## 6. 设计 token

- [ ] 浅色：#F1F5F9 背景 / #FFFFFF 抽屉 / #F8FAFC 卡片 / #0F172A 一级 / #64748B 二级 / #10B981 / #F59E0B / #EF4444。
- [ ] 深色：#0B0F19 / #1E293B / #0F172A / #F8FAFC / #94A3B8 / #34D399 / #FBBF24 / #F87171。
- [ ] 标题/单位 13pt，状态胶囊 11pt；双基准 28pt，一级网格 22–24pt，三级 18–20pt。
- [ ] 所有数字 tabular-nums，滚动/跳字无水平抖动。
- [ ] 抽屉满宽、顶部 28pt 圆角、拖拽条 36×4pt 距顶 8pt、头部/内容边距 16pt。

## 7. 回归

- [ ] 开始称重、蓝牙关闭、未绑定、扫描中、连接中、测量中状态均可到达。
- [ ] 设置、配对、成员选择、全部历史、删除、日志/抓包入口不丢失。
- [ ] 测量完成仍写入数据库，成员绑定/重算/Health Connect 行为不变。
- [ ] 旧 HistorySheet 仅在「全部历史」入口打开，不再自动弹出。
