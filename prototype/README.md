# 身体报告 · 可交互 HTML 原型

独立于 Android 实现的视觉走查原型。单文件、无构建、无外部依赖，全部 CSS/JS/SVG 内联。

- 页面：`prototype/body-report.html`
- 设计基准：375 × 812（pt 按 CSS px 1:1 还原）
- 桌面：居中 375 × 812 手机框；窗口高度不足时等比缩小，保持完整画幅
- 移动端（≤ 640px）：全屏铺满，使用 `100dvh` 与 safe-area

## 打开方式

直接双击或用浏览器打开：

```
prototype/body-report.html
```

不需要本地服务器、npm install 或任何构建步骤。推荐 Chrome / Edge / Safari 最新版。

### 无头截图/验收稳定态

页面支持 URL 查询参数，**带任意参数时不会自动播放测量时序**，会稳定停在指定状态：

```
prototype/body-report.html?sheet=half&theme=light&demo=normal
prototype/body-report.html?sheet=full&theme=dark&demo=normal
prototype/body-report.html?sheet=full&theme=light&demo=nobia
prototype/body-report.html?sheet=half&theme=light&demo=first
prototype/body-report.html?sheet=half&theme=dark&demo=offline
```

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| `sheet` | `collapsed` / `half` / `full` | 抽屉三态；缺省为 `half` |
| `theme` | `light` / `dark` | 明暗主题；缺省 `light` |
| `demo` | `normal` / `nobia` / `first` / `offline` | 四种演示数据；缺省 `normal` |

不带参数时，页面加载 700ms 后自动播放一次「测量完成」时序，便于直接查看动效。

## 交互清单

### 主舞台

- **状态胶囊**：点击在「半展开 → 全展开 → 半展开」之间切换；离线状态下点击会重新连接并播放测量时序。
- **240pt 表盘**：4pt 渐变环 + 60 格刻度 + 环境虚线环；中心 64pt 体重数字、18pt `kg`、差值胶囊。
- **主按钮**：正常/首次/无 BIA 状态下为「再测一次」或「开始测量」；离线状态为「连接设备」；测量过程中自动禁用并显示 spinner。
- **成员胶囊**：点击循环切换成员，同步更新报告、时间轴与趋势图。
- **阶段摘要 / 全部报告**：点击进入全展开抽屉；底部保留「全部历史」入口（原型内为 toast 提示）。

### 抽屉

- **拖拽**：按住拖拽条或标题区上下拖动；释放后按速度/距离吸附到最近锚点。
  - 阈值：400 px/s；弹簧 `stiffness=280, dampingRatio=0.82`
  - 拖拽只绑定头部，时间轴/成员筛选可横向滑动，抽屉内容可纵向滚动
- **点击/轻触标题区**：收起 → 半展开 → 全展开 → 半展开。
- **展开按钮**（标题右侧）：在半展开与全展开之间切换。
- **遮罩**：全展开时 45% 不透明；点击遮罩回到半展开。`Esc` 逐级收起。
- **单次 / 周均 / 月均**：分段控制器，切换后重新聚合时间轴与趋势数据。
- **横向时间轴**：44pt 高，点击任意快照切换当前报告；时间轴沿用契约的「最新在左、更早往右」，选中项自动滚入可视区。
- **多成员筛选**：全部 / 林小满 / 陈屿 / 王小北；「全部」在周均/月均下做跨成员聚合。
- **8 张指标卡**：点击选中并绘制 1.5pt 主色描边；若当前不是全展开，会自动展开抽屉并回到顶部。
- **趋势图**：180pt SVG 自绘，默认体重；折线 + 面积渐变 + 选中点发光锚点；单点时显示「再测一次即可连成趋势曲线」；点击折线上的点可切换快照。
- **Bento 网格**：严格 76 / 96 / 84 / 68pt 行高、10pt gap、16pt 圆角；三色区间条（偏低/标准/偏高）+ 状态标签 + 差值胶囊。

### 演示控制台

桌面左下角固定面板；窗口宽度 ≤ 1100px 时收纳为右下角「演示」按钮。

- **正常报告**：3 位成员、14 次历史、有 BIA、可看完整 8 项。
- **无 BIA**：最近一次仅记录体重与 BMI；6 张体成分卡显示 `--`，插入 36pt 提示条。
- **首次使用**：仅 1 条记录；体重卡显示「首次基准记录」，无差值胶囊；趋势图为单点。
- **离线历史**：无设备连接，展示 28 小时前缓存；状态胶囊「未连接设备 · 点击唤醒测量」，初始半展开。
- **浅色 / 深色**：即时切换交付方案 token，趋势图同步重绘。
- **模拟测量完成**：重播完整时序。

### 自动时序（T 为测量完成时刻）

| 时间 | 行为 |
| --- | --- |
| T+0 | 锁定阶段，体重数字两次 150ms 透明度闪烁 |
| T+300 | 进入分析阶段，4pt 流光环顺时针扫描 1000ms，数字快速跳动 |
| T+1300 | 抽屉弹簧至半展开（62%），主舞台 0.72 / 上移 80pt |
| T+1500 | 4 行卡片以 50ms/行 stagger 渐显，数字 400ms 从 0 滚动到实测值 |

## 调试 API

页面加载后可在 Console 调用：

```js
window.__setDemo('normal' | 'nobia' | 'first' | 'offline')
window.__setSheet('collapsed' | 'half' | 'full')
window.__setTheme('light' | 'dark')
window.__replay()          // 重播测量完成时序
window.__state()           // 读取当前 demo/theme/sheet/metric/phase 等状态
```

## 配色增强

每个指标卡现在拥有独立的强调色（体重蓝、BMI 紫、体脂橙、肌肉青、水分天蓝、内脏玫红、蛋白质靛蓝、骨量蓝绿），并应用到卡片微渐变、数字、区间游标、选中描边与趋势线；健康状态仍由绿/黄/红语义色单独承担，不与指标强调色混淆。

## 设计实现对照

### 层级

| Z | 层 | 内容 |
| --- | --- | --- |
| 0 | 背景 | `#F1F5F9` / `#0B0F19` + 蓝/青/紫微光 + 低透明度网格 |
| 10 | 主舞台 | 状态胶囊、表盘、体重数字、流光环、主按钮、成员/历史入口 |
| 20 | 遮罩 | 全展开 45%，其余为 0 |
| 30 | 抽屉 | 92% 固定高容器 + translateY 位移，顶部 28pt 圆角 |

### 抽屉几何（812 基准）

- 收起 12%：顶距 715px，位移 80% × 812 = 649.6px
- 半展开 62%：顶距 308px，位移 30% × 812 = 243.6px
- 全展开 92%：顶距 65px，位移 0
- 主舞台：`scale 1.00 / 0.72 / 0.50`，半展开上移 80pt，全展开再上移 16pt；`transform-origin: 50% 32%`
- 内容滚动补偿：半展开时给 `sheet-body` 增加与位移等量的底部 padding，保证最后一张卡片能滚到可视区

### Token

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | `#F1F5F9` | `#0B0F19` |
| 抽屉 | `#FFFFFF`（94%） | `#1E293B`（94%） |
| 卡片 | `#F8FAFC` | `#0F172A` |
| 一级文字 | `#0F172A` | `#F8FAFC` |
| 二级文字 | `#64748B` | `#94A3B8` |
| 达标 | `#10B981` | `#34D399` |
| 临界 | `#F59E0B` | `#FBBF24` |
| 高危 | `#EF4444` | `#F87171` |

主色取 Miuix 语义蓝的近似值（浅 `#2563EB` / 深 `#60A5FA`），仅用于选中描边、按钮和趋势线；状态色严格使用上表。

### 数据口径

- 成员：林小满（女 28 岁 / 164cm）、陈屿（男 31 岁 / 178cm）、王小北（男 26 岁 / 175cm）。
- 14 条历史数据，按 ISO 周或自然月聚合；聚合时缺失的体成分值不参与平均。
- 内脏脂肪为 1–9 / 10–14 / ≥15 三档演示值；无 BIA 时 6 项体成分为 `--`。
- 所有阈值、范围条和差值均按契约文档 `docs/BODY_REPORT_UI_CONTRACT.md` 生成。
- 原型数据均为演示 mock，不构成医疗建议。

## 自检

已用 Node（`node:vm`）对单文件执行以下检查：

- 内联脚本语法编译通过（无第三方依赖）
- HTML 标签配对/闭合通过
- 所有 JS 使用的 `#id` 选择器均存在，ID 无重复
- 8 张 `data-metric` 卡片齐全，顺序为 体重/BMI/体脂/肌肉/水分/内脏/蛋白质/骨量
- 无 `<script src>`、无外部样式表、无 CDN、无 `@import`
- 关键几何/时序/token 在 CSS/JS 中可检索（240、64、4、76/96/84/68、10、16、28、12%/62%/92%、45%、1.5px、300/1300/1500、50ms/400ms、280/0.82、400）

## 已知范围

- 这是视觉/交互原型，不连接蓝牙、不读写数据库、不做真实体成分计算。
- 数据不会持久化；刷新页面回到默认演示数据。
- 时间轴的「最新在左」遵循 `BODY_REPORT_UI_CONTRACT.md` 的快照顺序约定；趋势折线本身按时间从旧到新从左到右绘制。
